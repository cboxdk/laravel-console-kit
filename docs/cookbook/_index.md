# Cookbook

The plugin pattern has two sides. Each recipe below is a self-contained brief you can
hand to an AI coding agent (Claude Code) or a developer.

- **[Adopt the plugin pattern (prompt)](adopt-the-plugin-pattern-prompt.md)** — the
  host side (seed nav + `CurrentContext`, render the registry, guard routes) and the
  plug side (a package that registers into the hooks and gates itself), in one brief.
- **[Adopt the shared shell](adopt-the-shell.md)** — move an app onto the one Cbox
  shell: URLs, levels, nav, routes, rendering and tests.
